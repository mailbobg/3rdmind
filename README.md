# 3rdmind

量化因子研究工作台：让 Agent 提出假设、生成因子并在 Qlib 上验证，人来挑选、组合、回测、保存为策略并持续跟踪。

说明文档见 [docs/studio.md](docs/studio.md)，启动脚本见 [scripts/start-studio.sh](scripts/start-studio.sh)。

---

研究引擎基于 [microsoft/RD-Agent](https://github.com/microsoft/RD-Agent)（MIT），回测依赖 [microsoft/qlib](https://github.com/microsoft/qlib)（MIT）。原始版权声明见 [LICENSE](LICENSE)。
