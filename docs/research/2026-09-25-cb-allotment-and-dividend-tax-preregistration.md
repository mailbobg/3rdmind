# 预注册：转债发行抢权、除息前后的红利税（2026-09-25，取数之前写定）

来源：2026-09-25 的 GitHub / 文献调研（docs/research/2026-09-25-github-hypothesis-survey.md）筛出的两条未测过、有具名行为人、数据可得的假设。方法与此前所有事件研究相同；每条只做一次写定的主检验。

## 统一方法

- 事件日 e = 事件日期当天（公告按印刷日期在开盘前可见）；持有从 e 收盘起算，窗口第 k 日 = 收益日 e+k。
- 日历时间组合：每天等权持有处在窗口内的股票，减去当天全 A 等权收益；持仓少于 20 只的日子不计（窄窗口的检验改为持仓少于 5 只不计，下面单独写明）。月度加总后算 t。
- 单事件读法同时报告：每个事件窗口内的累计超额（CAR）均值，按事件月份聚合后的 t。
- 通过标准（两条都要满足）：全样本月度 t ≥ 2；前后两半（2019-01 → 2022-12，2023-01 → 2026-09）超额同为预期方向。
- 价格：quantdb 导出的 Qlib 目录，2019-01-02 → 2026-09-25，全 A 去北交所。

## H-F 转债发行的股权登记日抢权（强制流 / 制度）

行为人：可转债对原股东优先配售，配售权在股权登记日 R 收盘持股者手里；想拿配售权的投资者在 R 之前买正股，R 之后没有理由继续持有。转债上市溢价越高、每股含权越多，抢权动机越强。

- 数据：Tushare `cb_issue`（ann_date 发行公告日、shd_ration_record_date 股权登记日、shd_ration_ratio 每股配售面值、issue_size），quantdb 新表 `cb.issue`；`cb.basic` 取正股代码；价格来自 Qlib。
- 事件：每只转债的发行公告日 A（印刷日期）与股权登记日 R，R > A 的才算；同一正股同一天多只合并。
- 主检验：正股从 A 收盘持有到 R 收盘（收益日 A+1 … R），超额为正。窗口通常只有 1–2 个交易日，持仓少于 5 只的日子不计。
- 预期幅度受含权价值约束：每 100 元正股的含权 = shd_ration_ratio / 正股价 × 100，乘上转债上市溢价（历史约 10–30%）才是抢权能拿到的价值，量级 0.3–1%。所以另立一条**可交易门槛**：窗口平均超额减去 0.2% 双边成本仍为正，否则即便 t 通过也不做成规则。
- 只作描述、不作判定：R+1 … R+3（卸货）；A−10 … A（发行公告前是否已经提前反应，因为注册批文更早）；按含权价值分三组。
- 已知局限：样本每年 100–150 只，7 年约 900 个事件；正股多为中小盘，滑点大；发行公告日与登记日之间常只隔一天。

## H-G 除息日前后的差别化红利税（制度）

行为人：A 股红利税按持股期限差别征收（不满 1 个月 20%，1–12 个月 10%，满 1 年免）。持股不满一年的持有者在除息日持股要多缴税，有动机在除息前卖出、除息后再买回；免税的长期持有者和机构是对手方。这是税法规定出来的、时间点确定的交易动机。

- 数据：Tushare `dividend`（div_proc、ex_date、record_date、cash_div_tax、ann_date、imp_ann_date），quantdb 新表 `cn.dividend`；`cn.daily` 收盘价算股息率。
- 事件：div_proc = 实施、cash_div_tax > 0 的除息日 X；条件：税前股息率 = cash_div_tax / 实施公告日收盘价 ≥ 2%（红利税才值得躲）；同一股票同一除息日合并。
- 主检验：从 X 收盘持有 10 个交易日（收益日 X+1 … X+10），超额为正（税驱动的卖出在除息日结束，价格回补）。
- 只作描述、不作判定：X−20 … X−1 与 X−5 … X−1（除息前是否有卖压或抢权）；X 当天（用复权价，若除息日跌幅小于股息，复权收益为正）；按股息率 2–4% / 4–6% / ≥ 6% 分组；股息率 < 2% 的作为对照。
- 已知局限：除息日附近常有年报、分红方案等其他信息；高股息股集中在银行、公用事业，行业效应要看描述性结果；文献里的除息前正、后负是 2013 年差别化税制之前的样本，方向可能相反，这里写定主检验方向为除息后为正，反向的结果算不通过。

## 通用规则

通过的才做成规则、按真实成交回测；不通过的就此结束，不改窗口、不换阈值、不换集合。
