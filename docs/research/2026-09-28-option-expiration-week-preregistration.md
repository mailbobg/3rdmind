# 预注册：美股期权到期周效应（2026-09-28，取数之前写定）

动机：QuantConnect 策略库里少数带具名行为人的一条。Stivers & Sun（2013）发现标普 100 这类期权活跃的大盘股在月度期权到期周（第三个星期五所在的那一周）收益系统性偏高，归因于做市商在期权时间价值加速衰减时的 Delta 对冲再平衡。2022 年起每日到期的 0DTE 期权占了指数期权成交的大头，月度到期周的特殊性可能已经消失，所以这条同时检验「效应是否还在」。

## 数据

- 价格：`~/.qlib/qlib_data/us_ndx`，2007-06 → 2026-09-25，1,357 只大中盘。
- 期权活跃的大盘股集合：纳斯达克 100 当时的成分（月初快照，取事件前最近一份非空快照），等权。
- 对照集合：`all` 里不在纳斯达克 100 的股票（中盘为主，期权活跃度低），等权。

## 事件

每个月的期权到期周：到期日 = 该月第三个星期五（闭市则取其前最后一个交易日），到期周 = 到期日之前的 4 个收益日（星期一收盘买入、到期日收盘卖出，与之前所有事件研究的「e 收盘起持有」一致，e = 到期周的星期一）。2008-01 → 2026-09，约 225 个到期周。

## 主检验

纳斯达克 100 等权组合在到期周的 4 日收益，减去同一组合在**同月其它各周**同样 4 日窗口（星期一收盘到星期五收盘）收益的均值。每月一个差值，t ≥ 2 且前后两半（2008–2016，2017–2025）均值同为正才通过。这是长多能拿到的那部分：到期周比平常周多赚的钱。

## 只作描述、不作判定

- 截面读法：到期周里纳斯达克 100 减对照集合的超额（做市商对冲只作用在期权活跃的股票上，对照组应当没有）。
- 按 2022-01-01 前后分段（0DTE 普及前后）。
- 逐日剖面：到期周星期一到星期五各天，以及到期后一周。
- 五日版本（前一个星期五收盘买入，含星期一）。

## 已知局限

- 时间序列检验的样本是月份（约 225 个），效应本来就小（文献里到期周比其它周多约 0.3–0.5%），统计力有限。
- 到期周常与其它日历事件重叠（月中宏观数据、季度财报季），没有剔除。
- 纳斯达克 100 成分只有月初快照，月内变动忽略。

通过的才做成规则、按真实成交回测；不通过的就此结束，不改窗口、不换集合。

## 结果（2026-09-28，按上文口径一次跑出，未改任何设定）

225 个到期周（2008-01 → 2026-09），纳斯达克 100 等权组合平均 83 只有价格。

| 检验 | 均值（4 日） | t | 正占比 | 2008–16 / 2017–25 | 2008–21 / 2022–25（0DTE 前后） | 判定 |
|---|---|---|---|---|---|---|
| **主检验** 到期周 − 同月其它周 | −0.06% | −0.35 | 0.52 | +0.13% / −0.24% | +0.07% / −0.46% | **不通过** |
| 描述：到期周绝对收益 | +0.23% | 1.34 | 0.57 | +0.38% / +0.08% | | |
| 描述：同月其它周绝对收益 | +0.29% | 2.91 | 0.66 | +0.26% / +0.32% | | |
| 描述：截面 到期周 NDX − 对照集合 | +0.06% | 0.73 | 0.53 | +0.01% / +0.10% | +0.11% / −0.11% | |
| 描述：五日版（含星期一） | +0.24% | 1.29 | 0.60 | | | |

读法：到期周不比平常周好，2017 年以后还略差；截面上纳斯达克 100 相对中盘对照组也没有到期周的额外收益，0DTE 普及后转负。文献里 2013 年报告的效应在这份 2008 年起的样本里没有出现。到期后的那一周（+0.39%，t 2.06）是事后看到的，不算数，也没有机制解释。逐年的到期周差值正负各半。这条就此结束。
