# 预注册：美股月末月初效应、隔夜效应（2026-09-28，取数之前写定）

两条都是公开几十年的日历效应，各有行为人。放在最后做，是因为公开越久越可能已被套利掉；检验的重点是**现在还在不在**，以及扣掉交易成本还剩不剩。

## 数据

`~/.qlib/qlib_data/us_ndx`：1,357 只大中盘的日线（开、收），2007-06 → 2026-09-25；纳斯达克 100 指数本身（`^ndx`，QQQ 的可交易代理）。纳斯达克 100 成分按月初快照。样本 2008-01 → 2026-09。

## H-J 月末月初（turn of the month）

行为人：美国工资和 401(k) 按月发放并定投进指数基金，月末机构调仓与现金流入集中在月末最后一天到月初前几天（Lakonishok & Smidt 1988 定义 TOM = 最后一个交易日 + 次月前三个交易日）。

- 事件：每月 TOM 窗口 = 当月最后一个交易日前一日收盘买入，持有 4 个收益日（最后一日 + 次月前三日）。
- 主检验：纳斯达克 100 等权组合的 TOM 4 日收益，减去同月其它各个 4 日窗口（每周一收盘起）的平均收益；每月一个差值，t ≥ 2 且前后两半（2008–2016，2017–2025）同为正。
- 描述：四天逐日剖面；指数 `^ndx` 版本；截面（成分 − 对照中盘）；按 2022 前后分段。

## H-K 隔夜效应

行为人：隔夜（收盘到次日开盘）与日内（开盘到收盘）面对的是不同的交易者群体，美股的收益长期集中在隔夜（Kelly & Clark 2011；Lou, Polk & Skouras 2019）。

- 事件：每个交易日，收盘买、次日开盘卖。
- 主检验：`^ndx` 的隔夜收益均值 > 0，t ≥ 2，前后两半同为正；**并且**扣掉每天 0.02%（QQQ 买卖价差往返）后年化仍为正。三条都满足才通过。
- 描述：日内收益（开盘到收盘）；纳斯达克 100 等权组合的隔夜与日内；按 2022 前后分段；逐年。
- 已知局限：Yahoo 的开盘价质量不如收盘价（早年偶有错价），用 0.5 的单日收益上限剔除异常；指数开盘价与 QQQ 开盘价有微小差异。

通过的才做成规则、按真实成交回测；不通过的就此结束。

## 结果（2026-09-28，按上文口径一次跑出，未改任何设定）

### H-J 月末月初：不通过

224 个 TOM 窗口（2008-01 → 2026-08）。

| 检验 | 4 日均值 | t | 正占比 | 2008–16 / 2017–25 |
|---|---|---|---|---|
| **主检验** TOM − 同月其它周（NDX 等权） | +0.09% | 0.47 | 0.51 | +0.20% / −0.01% |
| 描述：TOM 绝对收益（等权 / `^ndx`） | +0.39% / +0.37% | 2.25 / 2.20 | | |
| 描述：其它周绝对收益（等权） | +0.30% | 3.28 | | |
| 描述：截面 TOM NDX − 对照 | +0.08% | 1.10 | | |

TOM 那四天是赚钱的（+0.39%），但同月其它周也赚（+0.30%），差值不显著，2017 年后为零。逐日剖面里最后一个交易日 +0.02%，月初三天 +0.16 / +0.12 / +0.10，都不显著。这条效应在纳斯达克 100 上已经没有了。

### H-K 隔夜：写定的三条都满足，但不做成策略

4,713 个交易日（2008-01-02 → 2026-09-25）。

| 检验 | 日均 | t | 2008–16 / 2017–25 | 2008–21 / 2022–25 |
|---|---|---|---|---|
| **主检验** `^ndx` 隔夜（收盘 → 开盘） | +0.033% | 2.75 | +0.017% (1.01) / +0.049% (2.76) | +0.033% (2.43) / +0.033% (1.30) |
| 描述：`^ndx` 日内（开盘 → 收盘） | **+0.034%** | 2.01 | +0.031% / +0.037% | |
| 描述：NDX 等权 隔夜 / 日内 | +0.035% / +0.032% | 2.97 / 1.90 | | |

年化：隔夜 +8.4%，扣 0.02%/日的往返价差后 +3.4%。t ≥ 2、两半同正、扣费为正，写定的三条都过了。

但描述性结果把这条否了：**日内收益和隔夜一样大**（+0.034% vs +0.033%）。文献说美股收益集中在隔夜、日内为零，纳斯达克 100 在这份样本里不是这样，两段各占一半。隔夜策略每天进出一次，拿到一半的收益、付全部的成本，年化 +3.4%；什么都不做持有指数，年化约 +16.8%、零成本。逐年看隔夜在 2008（−17%）和 2022（−20%）也没有躲过下跌。预注册的通过标准里漏了「要比持有强」这一条，是我写定时的疏忽，但结论不因此改变：这不是一个值得下单的策略，不登记。2022 年后隔夜的 t 只有 1.30，效应本身也在弱化。

两条到此结束。美股这一轮七条（因子循环、Form 4、PEAD、纳斯达克 100 调整、期权到期周、月末月初、隔夜）没有一条能变成策略。
